## 1. Brand Tokens & Color Palette
- **Primary Blue**: `#003D9B` (Royal Blue)
- **Primary Container / Action Button**: `#0052CC` (Action Blue)
- **Secondary Slate**: `#434654`
- **Surface Level 0**: `#FAF8FF` (Soft Off-White)
- **Surface Level 1 Card**: `#FFFFFF` / `#EDEDF8`
- **Customer Accent**: `#A33500` (Coral/Orange)
- **Driver Accent / Online**: `#00C853` (Vibrant Emerald Green)
- **Restaurant Theme**: Dedicated high-contrast slate-white palette for kitchen visibility (`RestaurantTheme`)

## 2. Typography Hierarchy (Inter)
- **Display Large**: 32pt, Weight 900, Letter Spacing -0.5px
- **Headline Large**: 26pt, Weight 800, Letter Spacing -0.3px
- **Headline Medium**: 20pt, Weight 700
- **Title Large**: 18pt, Weight 700
- **Body Large**: 16pt, Weight 400
- **Label Large**: 15pt, Weight 800

## 3. Kinetic Responsiveness & Components
- Micro-animations for category transitions, banner page indicator dots, hover states.
- High-contrast rating chips (`4.8 ★`), delivery ETA badges (`20 mins`), and distance chips (`1.2 km`).
- Responsive layout rules for tablet and desktop admin interfaces.
