## Proposed Remediation for Identified Gaps

Rather than generating dozens of redundant screens that inflate maintenance overhead, the audit proposes **4 targeted screen additions / visual extensions**:

| Target Module | Proposed Screen ID | Proposed Screen Name | Justification | Priority |
|---|---|---|---|---|
| **Super-App** | `SA-GAP-01` | Mandatory Landmark Address Guard | Displayed when user selects a pin without a verified landmark; blocks blind dispatch. | **P0** |
| **Ride** | `RD-GAP-01` | Multi-Stop Waypoints Bottom Sheet | Allows adding intermediate stopovers with route re-calculation. | **P1** |
| **Food** | `FD-GAP-01` | Section 9(5) Statutory Tax Modal | Explains 5% restaurant GST vs delivery partner platform GST to customers. | **P1** |
| **Grocery** | `GR-GAP-01` | Multi-Slab GST Invoice View | Breaks down 0%, 5%, 12%, 18% itemized GST slabs on completed kirana delivery. | **P1** |
