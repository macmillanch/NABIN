# Mobile App Builder Agent — NABIN

## Responsibilities
- Build and refine Flutter applications under `mobile/lib/` for NABIN Customer (`main_customer.dart`), NABIN Driver (`main_driver.dart`), and NABIN Merchant (`main_restaurant.dart`).
- Shared modular packages and models (`core/models/`, `core/theme/`, `features/`).
- Seamless state management, real-time socket/polling state updates, interactive maps, and responsive form validation.
- Enforce reusable components across Ride, Food, Parcel, and Account features.
